# Privacy Policy — Civitai Pro Tools

*Last updated: June 2026*

## Overview
Civitai Pro Tools ("the Extension") is a browser extension for extracting and enhancing image generation parameters on Civitai.com. This policy explains how data is handled.

## Data We Collect
**We collect no user data.**

The Extension does not transmit, store, or share any personal information with the developer or any third party, except as described below.

## Data Stored Locally
The following data is stored exclusively in your browser's local storage and never leaves your device:

- **Claude API Key** — entered by the user, stored locally, used only to call Anthropic's API directly from your browser
- **Extraction history** — up to 50 recent parameter extractions, stored locally for your personal reference

## Third-Party Services

### Anthropic (Claude API)
When you use AI features (Improve, Explain, Variations), your prompt text is sent directly from your browser to Anthropic's API. This is governed by [Anthropic's Privacy Policy](https://anthropic.com/privacy).

### ExtensionPay
Payment processing for the one-time license is handled by ExtensionPay. Purchase authentication uses Google's identity service. No payment card data is accessible to the Extension or the developer. See [ExtensionPay's Privacy Policy](https://extensionpay.com/privacy).

## Permissions Explained
- **storage** — saves your API key and history locally in your browser
- **activeTab** — reads the current Civitai page to extract generation parameters
- **clipboardWrite** — copies extracted data to your clipboard on request
- **identity** — used by ExtensionPay to verify your purchase status via Google

## No Tracking
The Extension contains no analytics, no telemetry, and no advertising code.
